## 📋 QUY TẮC LƯU TRỮ

### Đặt tên file:
```
Idea-hoa-[ten-idea-viet-tat]-V1.md
```
Ví dụ: `Idea-hoa-trash-can-fence-V1.md`

### Phân loại:
- Mỗi idea lưu vào folder của **HOA pattern chính** (primary pattern)
- Nếu idea có **combo patterns** (VD: Malicious Compliance + Board Takeover), lưu vào pattern **MẠNH NHẤT** và ghi chú combo trong file
- Xem `Pattern` field ở đầu mỗi file đánh giá để xác định folder
- **CHỈ LƯU idea liên quan HOA** — idea ngoài HOA lưu vào `_Archive-Non-HOA/`

### Khi nào idea được lưu vào đây:
- Sau khi chạy workflow `/danh-gia-idea` → file tự động lưu vào folder tương ứng
- Idea cũ từ `Research/` đã được migrate sang đây
