## 📋 CÁCH SỬ DỤNG

### Khi CÓ IDEA → Đánh giá:
1. Đọc idea → Xác định match **pattern nào** trong 9 file bên dưới
2. Mở file pattern tương ứng → Chấm điểm idea theo **Checklist Đánh Giá**
3. Nếu idea match ≥2 patterns → **CỘNG HƯỞNG** = tiềm năng cao hơn
4. Xem **Cạm bẫy** để kiểm tra red flags
5. Kết quả: PASS (tiến hành `/danh-gia-idea`) hoặc cần refactor

### Khi CHƯA CÓ IDEA → Brainstorm:
1. Duyệt từng file pattern → Đọc **Idea Starters** ở cuối mỗi file
2. Chọn pattern phù hợp → Kết hợp với **Nhân vật yếu thế** hoặc **Dual theme**
3. Test nhanh bằng **Công thức tiêu đề** trong mỗi file
4. Nếu tiêu đề gây "WTF, phải nghe tiếp!" → Idea PASS
